## Install
1. Download `DeskGuardSetup.exe` below
2. Run it - no admin rights needed
3. On the finish screen, enroll your face and start Desk Guard

That's it. Full docs: see README.md.

**Note:** Windows may show a SmartScreen warning ("Windows protected your
PC") since this isn't code-signed - click "More info -> Run anyway" if you
trust the source.
